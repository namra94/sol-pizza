sol.pizza — deploy the built site to the sol-pizza Worker

Needs Node.js (nodejs.org, LTS). Then, in Terminal, inside this folder:

  npx wrangler login       # first time only — opens your browser, click Allow
  npx wrangler deploy      # uploads ./dist to the sol-pizza Worker (~10 seconds)

That's it. The site is live as soon as the second command finishes.
